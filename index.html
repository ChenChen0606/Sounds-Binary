Explain It

1. In your own words, how does your app change a sound wave into binary?

It works in three steps: it samples the wave's height at equal time steps, rounds each height to the nearest level, and then writes each level in binary with leading zeros.

2. Run Test A again with 2 bits, then 6 bits. Which gives more detail about the wave, and why?

6 bits gives more detail because it has 64 levels instead of 4, so each sample is rounded less and the binary follows the wave's height more closely. It also uses more bits.

3. Which test has the longest wavelength? How is wavelength connected to frequency?

Test B (200 Hz) has the longest wavelength, 1.72 m. Wavelength is 343 ÷ frequency, so a higher frequency gives a shorter wavelength.

4. What was the hardest stage to build, and how did you fix it?

Stage 4 (the level and binary) was the hardest, because tiny decimal errors like 0.00000000000000012 sometimes gave the wrong level. I fixed it by rounding the height to 9 decimal places before finding the level.
